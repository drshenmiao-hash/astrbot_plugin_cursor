环境与连接

  1. 在插件设置选择运行方式。可在下方先检查该方式，确认 CLI 和所需系统组件。
  2. 由管理员安装缺少的组件，在 CLI 所在环境登录 Cursor，并在插件设置填写模型 ID、保存。
  3. 检查 ACP 连接和模型校验，再在 AstrBot 选择已启用的 Cursor 模型开始聊天。

直接运行没有文件系统沙盒。CLI 可访问 AstrBot 运行用户有权访问的文件。临时 HOME、Ask 模式和工具限制不能代替系统隔离。请使用低权限用户或受限容器。

仅检查依赖和登录材料。选择检查方式不会保存设置，也不会打开聊天连接。
